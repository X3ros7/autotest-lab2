# Специфікація бібліотеки `Matrix`

Специфікація написана до тестів і коду. Кожна вимога має ідентифікатор `R<N>`. Назви груп тестів у `test/` містять цей ідентифікатор, тому кожен тест можна простежити до вимоги.

## Загальні положення

- Матриця є незмінною (immutable): жодна операція не змінює операнди, результат завжди новий об'єкт `Matrix`.
- Елементи матриці є скінченними числами.
- Помилка типу або структури даних: `TypeError`.
- Помилка розмірності або індексу: `RangeError`.
- Спроба обернути вироджену матрицю: `Error` з повідомленням `Matrix is singular`.

## Вимоги

| ID | Вимога |
|----|--------|
| R1 | `new Matrix(data)` створює матрицю з непорожнього двовимірного масиву чисел. Властивості `rows` та `cols` містять розміри. Порожній масив, порожні рядки, рядки різної довжини, нечислові та нескінченні елементи, а також не масив дають `TypeError`. |
| R2 | `get(i, j)` повертає елемент з рядка `i` та стовпця `j` (нумерація з нуля). Індекс поза межами або не ціле число дає `RangeError`. |
| R3 | Матриця незалежна від масиву, з якого створена: зміна вхідного масиву не впливає на матрицю. `toArray()` повертає копію даних. Властивості `rows` та `cols` доступні лише для читання, внутрішнє сховище даних ззовні недоступне. |
| R4 | `Matrix.zeros(r, c)`, `Matrix.ones(r, c)` та `Matrix.identity(n)` створюють відповідні матриці. Розміри мають бути додатними цілими, інакше `RangeError`. |
| R5 | `a.equals(b, epsilon = 0)` повертає `true`, якщо розміри збігаються і відповідні елементи відрізняються не більше ніж на `epsilon`. Для не `Matrix` повертає `false`. |
| R6 | `add(other)` та `subtract(other)` виконують поелементні додавання та віднімання. Для різних розмірів `RangeError`, для не `Matrix` `TypeError`. |
| R7 | `scale(k)` множить кожен елемент на число `k`. Для не числа `TypeError`. |
| R8 | `multiply(other)` повертає добуток матриць розміру `a.rows x b.cols`. Підтримуються неквадратні матриці. Якщо `a.cols !== b.rows`, `RangeError`. Для не `Matrix` `TypeError`. |
| R9 | `transpose()` повертає транспоновану матрицю. |
| R10 | `isSquare()` повертає, чи рівні `rows` та `cols`. `trace()` повертає суму діагональних елементів, для неквадратної матриці `RangeError`. |
| R11 | `determinant()` повертає визначник квадратної матриці довільного порядку. Для неквадратної матриці `RangeError`. |
| R12 | `minor(i, j)` повертає матрицю без рядка `i` та стовпця `j`. `cofactor(i, j)` повертає число: визначник мінора, помножений на `(-1)^(i+j)`. Для індексів поза межами, а також для матриці з одним рядком або одним стовпцем (мінор був би порожнім) `RangeError`. |
| R13 | `inverse()` повертає обернену матрицю квадратної невиродженої матриці. Для неквадратної `RangeError`, для виродженої `Error('Matrix is singular')`. |

## Принципи розробки

1. Спочатку специфікація (цей документ).
2. Для кожної вимоги цикл TDD: тест, який падає (Red), мінімальний код, який його проходить (Green), рефакторинг без зміни поведінки (Refactor).
3. Кожна фаза циклу є окремим комітом у git: `test(Rn): ... [red]`, `feat(Rn): ... [green]`, `refactor: ... [refactor]`.
